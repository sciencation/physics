すべての電荷が「ある値の整数倍」になっているとすると，その値はいくらか。条件を満たす値のうち，最も大きいものを見積もろう（半分の値でも整数倍にはなってしまう）。

自動計算のしくみ

空気抵抗は krv（k = 3.39×10⁻⁴ N·s/m²，r は半径，v は速さ），質量は m = (4/3)πr³ρ。

静止法（半径を読む）：顕微鏡で半径 r を読んで質量 m を求め，電圧 V で静止させる。q(V/d) = mg　→　q = mgd / V。半径は光の点の大きさから読むので誤差が大きく，q ∝ r³ なのでその3倍の割合で q に効く。

落下・上昇法：電場OFFで落下させ，終端速度 v₁ を測る。mg = krv₁ と m = (4/3)πr³ρ から r と m が決まる。次に電圧 V で速さ v₂ で上昇させる。q(V/d) = mg + krv₂　→　q = kr(v₁+v₂)d / V。時間の測定は精度がよいので，q のばらつきは小さい。

油の密度 ρ = 9.0×10² kg/m³，g = 9.8 m/s²，極板間隔 d = 5.0 mm，A–B間 0.50 mm。
